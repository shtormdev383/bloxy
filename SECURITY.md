# Безопасность: что делает этот код

Репозиторий открытый, весь код читается целиком. Ничего не скачивается и не запускается «вслепую». Но сам по себе открытый код ничего не «доказывает» — проверь его (способы ниже) и запускай только то, что понял.

## Чего в проекте НЕТ
- Нет исполняемых файлов (`.exe`, `.dll`, `.bat`, архивов, бинарников) и нет кода, который их скачивает или запускает.
- Нет `eval`, `new Function`, `document.write`, `XMLHttpRequest`, `fetch` в `index.html`. Скрипты студии (русские команды вроде `на старте: сказать …`) разбираются обычным разбором строк, а не выполняются как код.
- Нет `subprocess`, `os.system`, `exec`, `eval`, `pickle` в Python-файлах.
- Нет сбора личных данных, аналитики, рекламы, майнеров, скрытых сетевых запросов.

## Куда обращается сайт (`index.html`)
| Что | Зачем |
|---|---|
| `fonts.googleapis.com` | шрифты (Baloo 2, Nunito) |
| `cdnjs.cloudflare.com`, three.js r128 | 3D-движок |
| `WebSocket` на **тот же сайт** (`/ws`) | только если запущен `server.py`: чат, форум, арена |
| `localStorage` | хранение аккаунта, покупок, настроек в твоём браузере |

Больше сетевых адресов в файле нет.

## Сервер (`server.py`)
- Принимает WebSocket на `/ws`, отдаёт `index.html` и `/health`.
- Хранит аккаунты, друзей и форум в JSON-файле. Пароли — PBKDF2-SHA256 с солью, в открытом виде не хранятся.
- Ограничивает частоту сообщений, длину текста и размер сообщения.
- Передавай пароли только по HTTPS (`wss://`); без шифрования — только в локальной сети.

## Как проверить самому
    grep -oE 'https?://[A-Za-z0-9./_-]+' index.html | sort -u
    grep -nE 'eval\(|new Function|document\.write|XMLHttpRequest|fetch\(' index.html
    grep -nE 'subprocess|os\.system|exec\(|eval\(|pickle|urllib|requests' server.py python-client/*.py
    sha256sum -c SHA256SUMS.txt

Файлы можно загрузить на virustotal.com для автоматической проверки (это помощь, а не гарантия). Нашёл проблему — открой Issue.
