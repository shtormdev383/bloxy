# BLOXLY

Игровая платформа в стиле Roblox, написанная на чистых **HTML / CSS / JavaScript**: игры (2D и 3D), друзья и чат, аватар в 3D, магазин, инвентарь и трейды, группы, форум, студия для создания своих уровней, настройки оформления. Один файл `index.html`, без сборки и без зависимостей.

> Неофициальный fan-проект. Не связан с Roblox Corporation и не использует её код, логотипы и файлы.

**Сделано: shtorm и Claude Sonnet 5.5.**

## Быстрый старт (без сервера)
Открой `index.html` в браузере или выложи на любой статический хостинг (GitHub Pages, Netlify, Cloudflare Pages). Данные (аккаунты, покупки, игры из студии) хранятся только в твоём браузере (`localStorage`).

GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `(root)`*.

## Мультиплеер и живой форум (нужен сервер)
`server.py` — маленький сервер на Python (aiohttp, WebSocket): раздаёт сайт, общий чат, друзья, арена с монетами и живой форум.

    pip install -r requirements.txt
    python server.py          # http://localhost:8765

Бесплатный хостинг (пример — Render): New → Blueprint → этот репозиторий (настройки в `render.yaml`). Бесплатные тарифы могут засыпать и сбрасывать файлы диска; условия меняются — проверяй на сайте хостинга.

## Python-клиент (необязательно)
В `python-client/` лежит настольный клиент на Tkinter и свой простой TCP-сервер. Работают отдельно от сайта. См. комментарии в файлах.
